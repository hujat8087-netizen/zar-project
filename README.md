# Zarchinar Restaurant

Zarchinar Restaurant is a local restaurant ordering, counter, inventory, billing, and accounting system.

## Run on a computer

1. Install Node.js and MongoDB.
2. Copy the complete project folder to the computer.
3. Double-click `start-server.bat`, or open a terminal in the project folder and run `npm start`.
4. Open `http://127.0.0.1:3001` in the browser.

The root address opens the Zarchinar Restaurant login. The server listens on the local network too, so other devices on the same Wi-Fi can use the computer's LAN IP with port `3001`.

Zarchinar Restaurant uses port `3001` by default so it stays separate from other local projects that may use port `3000`.

## Main pages

- Login: `http://127.0.0.1:3001`
- Waiter: `http://127.0.0.1:3001/waiter.html`
- Delivery: `http://127.0.0.1:3001/delivery.html`
- Counter and management: `http://127.0.0.1:3001/counter.html`

This application does not start or connect to the Zar Store application.
